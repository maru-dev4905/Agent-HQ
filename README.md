# Agent HQ

AI Agent의 실행 상태와 작업 흐름을 관찰하고, 관리하고, 궁극적으로 오케스트레이션하는 통합 플랫폼.
Agent를 위한 Headquarters — 전문적인 Dashboard와 게임화된 3D Office 두 가지 화면을 제공하는 것을 목표로 한다.

## 현재 상태

기술 스택은 미확정이다 ([ADR-0003](docs/decisions/ADR-0003-m1-tech-stack.md), Proposed).
